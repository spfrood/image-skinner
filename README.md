# image-skinner (formerly solo-teamer)
Solo creative toolset to generate character video by mapping a humans facial movement, body movement, and speech to animate a character based on AI generated sketches and AI generated voice samples. 

Project notes and description:
End goal is to develop a toolset that a solo creative will be able to use to voice and animate all of the characters in a video/anime/story/etc.
The theory behind the tool is that the creative will be able to film themselves performing an action or speaking lines and the tool will then 
create a video using character images and voice samples that performs the same action or says the same lines with the same intonation/inflection
as performed by the creator. This will theoretically enable one creative to animate and act out every character role in the story.
